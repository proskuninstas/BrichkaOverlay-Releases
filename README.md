# Brichka Overlay

Windows-приложение для отображения показателей компьютера и заряда периферии поверх окон.

Создано методом вайбкодинга с помощью Codex (OpenAI).

## Скачать

Откройте [последний релиз](https://github.com/proskuninstas/BrichkaOverlay-Releases/releases/latest).

- **BrichkaOverlay-Setup.exe** — установленная версия.
- **BrichkaOverlay-Portable.zip** — портативная версия: распакуйте всю папку и запустите BrichkaOverlay.exe. Настройки хранятся в Data рядом с программой.

Поддерживаются Windows 10/11 x64 с .NET Framework 4.8.

## Обновления

Начиная с 2.9.0 программа проверяет опубликованные стабильные версии. При включённых уведомлениях появляется уведомление Windows; надпись «Доступно обновление → Обновить» также доступна сверху в приложении, в том числе при выключенных уведомлениях. Нажатие скачивает и проверяет архив, сохраняет настройки, заменяет файлы приложения и перезапускает программу.

Для перехода с версии без встроенного обновления установите последнюю версию вручную. Для portable сохраняйте свою папку Data. Настройки проверки находятся в разделе «Настройки → Обновления».

Версия 3.9.2 добавляет наушники для всех тем, заливку заряда по видимому силуэту, единый масштаб значков карточек и исправляет применение графиков к старым датчикам с полоской. Исправление первого открытия настроек из трея сохранено. Подробности — в [описании релиза 3.9.2](https://github.com/proskuninstas/BrichkaOverlay-Releases/releases/tag/v3.9.2).

Если драйвер CPU ещё не установлен, для его первой настройки нужен интернет. Официальный фиксированный файл скачивается с GitHub и проверяется по SHA-256 до запуска. При наличии драйвера повторной загрузки нет.

В этом репозитории публикуются готовые сборки. Тексты лицензий компонентов включены в папку Licenses внутри дистрибутива.

Соответствующие исходники сторонних модулей PawnIO.Modules 0.1.6 включены офлайн с инструкцией восстановления архива и доступны отдельным ZIP-файлом в релизе. Для обычного запуска ZIP исходников скачивать не нужно. Поддержка: prokuninstas@yandex.ru.

## Публикация следующей версии

После сборки и проверки замените файлы в dist, обновите SHA256SUMS.txt и RELEASE-NOTES.md, затем измените version в release.json и отправьте один коммит в main. GitHub Actions проверит контрольные суммы и опубликует релиз с файлами. Уже опубликованные версии не перезаписываются.
