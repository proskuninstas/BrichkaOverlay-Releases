## Brichka Overlay 3.9.0

У каждой из 13 дополнительных тем появился собственный цветной набор иконок по пользовательским примерам. Под выбором темы доступны варианты графиков с предпросмотром; выбор сохраняется отдельно для каждого оформления. Стандартная тема сохранена.

Исправлено открытие настроек из трея: окно появляется с первого действия после фонового запуска и восстанавливается из скрытого или свёрнутого состояния. FPS/DLSS используют тематические значки; их геометрия не зависит от смены цифр.

В «О программе» добавлена добровольная поддержка с копированием номера. Для e-mail и номера есть явное подтверждение копирования. Убрана ссылка Telegram, добавлено описание создания приложения с помощью Codex. Все исходные C#-файлы снабжены русскими пояснениями в проекте.

Включены предыдущие локальные улучшения: темы, независимые переключатели графиков минимального и компактного режимов, читаемые предпросмотры, вертикальная компоновка и исправления кнопок лицензий и очистки кэша.

Отдельный установщик драйвера PawnIO больше не включён в пакет. Если драйвер отсутствует, первая настройка CPU скачивает фиксированный официальный файл по HTTPS и проверяет его SHA-256 до запуска. Для этого первого действия понадобится интернет. Уже настроенный драйвер повторно не скачивается; при обычном запуске Windows повторная настройка не требуется.

Соответствующие исходники встроенных модулей PawnIO.Modules 0.1.6, copyright и LGPL включены в программу. Обычный исходный ZIP также доступен ниже отдельным файлом. Он не нужен для обычного запуска приложения.

Проверки: 640 проверок установленной сборки, 211 проверок новых функций, установка и portable, обновление с сохранением настроек, совместимость пакета с публичным обновлятором 3.6.1. Все 32 контрольных изображения исходной стандартной темы сохранены.

- **BrichkaOverlay-Setup.exe** — установка или обновление установленной версии.
- **BrichkaOverlay-Portable.zip** — распакуйте целиком в отдельную папку.
- **PawnIO.Modules-0.1.6-source.zip** — соответствующие исходники сторонних модулей.
- **SHA256SUMS.txt** — контрольные суммы файлов.

Windows 10/11 x64, .NET Framework 4.8+. Настройки пользователей сохраняются.
