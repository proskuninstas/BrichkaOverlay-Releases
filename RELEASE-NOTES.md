## Brichka Overlay 3.9.1

Исправлено открытие настроек из трея после обновления и фонового запуска. Окно теперь показывается с первого нажатия, в том числе после скрытия и сворачивания.

Причиной был скрытый запуск Windows: приложение считало окно видимым, хотя Windows оставляла его скрытым. Добавлена отдельная проверка первого открытия в свежем процессе и фактической видимости окна.

Темы, иконки, графики и датчики сохранены. Пользовательские настройки сохраняются при обновлении.

Windows 10/11 x64, .NET Framework 4.8+. Setup — установка, Portable — распакуйте всю папку и запустите BrichkaOverlay.exe. ZIP исходников PawnIO.Modules предназначен для соблюдения лицензии стороннего компонента и не нужен для обычного запуска.
