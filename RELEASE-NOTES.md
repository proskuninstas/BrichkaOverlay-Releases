## Brichka Overlay 2.9.1

- Исправлена совместимость путей ZIP: обновления корректно распаковываются обработчиками Windows и предыдущей версии.
- Добавлена проверка обновлений через GitHub Releases при запуске и каждые 6 часов.
- При включённых уведомлениях доступная новая версия вызывает уведомление Windows.
- Надпись «Доступно обновление → Обновить» закреплена сверху в приложении и работает при выключенных уведомлениях.
- По нажатию программа скачивает обновление, проверяет размер и SHA256, сохраняет настройки, заменяет файлы и перезапускается.
- Обновление поддерживается для установленной и portable-версии; папка Data сохраняется.
- В настройках можно отключить автоматические проверки или проверить обновления вручную.
- Включено исправление 2.8.1 для ошибки 0x80070002 при первой настройке датчиков CPU.

**Первый переход на 2.9.1 выполняется вручную:** в предыдущих версиях функции обновления ещё нет.

Установщик: BrichkaOverlay-Setup.exe. Portable: распакуйте BrichkaOverlay-Portable.zip и запустите BrichkaOverlay.exe.
