## Brichka Overlay 3.2.0

- DLSS показывает прочерк, когда дополнительные кадры не наблюдаются: обычный FPS продолжает работать. Близкие показания больше не дублируются. Сравниваются реальные частоты исходных и показанных кадров, учитывается небольшой шум измерений.
- Надписи FPS/DLSS и значения стоят ближе друг к другу. Числа выводятся в постоянных ячейках: смена показаний и прочерк не меняют ширину оверлея.
- В «Игровом режиме» добавлены отдельные цветовые шкалы для надписей FPS и DLSS, независимое сохранение и сброс «По теме».
- Плавные переходы между страницами, категориями каталога, подразделами настроек и темами. Разметка обновляется целиком, без показа промежуточного пустого окна.

Также в этот публичный релиз входят изменения локальных версий 3.1.0–3.1.1:

- Раздел «Игровой режим», отдельные переключатели FPS/DLSS; показатели перед остальными категориями, включая вертикальную компоновку. Нет данных — прочерк. Источник кадров — PresentMon, без внедрения в игру.
- Температурные предупреждения CPU/GPU: независимые переключатели плавного красного мигания и критические пороги в «Настройки → Настройки оверлея».
- Прозрачная иконка Windows для EXE, панели задач и «Пуск», с обновлением собственных ярлыков.
- Современная тонкая полоса прокрутки настроек и исправленное центрирование по видимым краям значков.
- Исправлено обновление занятого системного модуля датчиков.

Для первого включения FPS на ранее установленной версии откройте «Игровой режим» и, если предложено, нажмите «Настроить модуль FPS один раз». Windows запросит разрешение администратора при настройке; обычный запуск затем обходится без повторного запроса. Разделение кадров зависит от данных игры и драйвера; отсутствие подтверждённых дополнительных кадров отображается прочерком.

Для обновления: «Настройки → Системные настройки → Обновления приложения → Проверить обновления», затем «Доступно обновление → Обновить». При выключенных уведомлениях надпись остаётся в приложении. Настройки сохраняются.

Установщик: BrichkaOverlay-Setup.exe. Portable: BrichkaOverlay-Portable.zip.
