## Brichka Overlay 2.9.2

- Полностью удалены звуки нажатия кнопок и проигрыватель.
- MP3 исключён из приложения и дистрибутивов.
- Переключатель «Звук кнопок» убран из главного меню.
- Старые настройки совместимы; прежний кэш встроенного звука удаляется при первом запуске новой версии.

Для проверки обновления в 2.9.1 откройте «Настройки → Обновления приложения → Проверить обновления». Сверху появится «Доступно обновление 2.9.2 → Обновить». Нажмите эту надпись для установки с сохранением настроек.

Установщик: BrichkaOverlay-Setup.exe. Portable: BrichkaOverlay-Portable.zip.
